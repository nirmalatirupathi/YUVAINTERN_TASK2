For Week 2, I completed a comprehensive Exploratory Data Analysis (EDA) and Visualization Framework for a hypothetical Customer Churn dataset. The purpose of this project is to define a structured and reusable Python-based process for understanding data quality, distributions, relationships, customer segments and potential modeling implications before machine-learning development. The framework begins with dataset intake and structural profiling, including row and column counts, data types, unique values, identifiers, missing values, duplicates and target-variable definition. It then covers univariate, bivariate and multivariate analysis for both numeric and categorical variables.

The project provides a detailed strategy for handling missing data and outliers. Missingness is assessed by column and relevant customer segment, while structural missingness is distinguished from accidental missingness. Candidate treatments include median imputation for appropriate numeric variables and an explicit Unknown category for suitable categorical variables, with decisions based on business context. Outliers are evaluated using boxplots, interquartile-range rules, robust statistics and domain thresholds rather than being removed automatically.

The visualization framework includes histograms, boxplots, bar charts, scatter plots, correlation heatmaps and segmented views. Python tools include pandas, NumPy, Matplotlib, Seaborn, Plotly and Jupyter. The repository contains the completed Word report, reusable EDA Python code, a proposed data dictionary, methodology and reporting documentation, requirements, and illustrative visualization examples. No real customer dataset was supplied for this internship task, so the visual examples are explicitly illustrative and no fabricated analytical findings or model results are claimed. The framework is designed to become a reproducible analysis workflow when an approved dataset is available.
